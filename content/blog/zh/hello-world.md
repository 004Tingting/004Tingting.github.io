2026 年了，为什么还要做个人网站？

社交平台负责流量，但版式归平台、算法归平台、账号也归平台。一个自己的站点是少数完全属于你的地方：**写什么、怎么排、留多久，都由你说了算。**

## 三个决定

### 双语

中文写起来最顺，但学术圈的通用语是英文。我选择双语而不是二选一——框架上双语，内容按需：重要的文章两边都发，随笔先发中文。完美对齐不是目标，写出来才是。

### 杂志排版

这个站看起来不像博客，更像一本「个人杂志」：衬线大标题、纸色底、一条朱红贯穿全文。没有缩略图，没有卡片阴影——层级全部交给字号、留白和细分隔线。文字是主角，排版即设计。

### 静态

整站由 Next.js 构建成纯 HTML，托管在 GitHub Pages：

```ts
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  output: "export",
};

export default nextConfig;
```

没有数据库，没有服务器账单，构建产物可以部署到任何静态托管。

## 会写什么

- **科研笔记** —— CAV 与滑模控制、有限时间稳定性，读到的好论文
- **工程记录** —— 故障诊断与寿命预测项目的方法与坑
- **开发日志** —— OinO 表情包管理器，以及这个网站本身
- **游戏设计** —— 从设计域切入的学习笔记
